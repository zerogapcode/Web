Postventa para Windows

Versión 1.0.6 · Windows 10 (1809 o posterior) u 11, 64 bits · 30.6 MB

La misma cuenta y los mismos datos que en el teléfono, en una ventana grande: la tabla de órdenes ordenable, la agenda y la bandeja a la vez, con atajos de teclado.

Descargar para Windows Certificado (.crt)

Instalación · la primera vez en cada equipo

  1. 1Descarga el certificado y ábrelo con doble clic. Pulsa «Instalar certificado» y elige «Equipo local».
  2. 2Marca «Colocar todos los certificados en el siguiente almacén», pulsa «Examinar», elige «Personas de confianza» y termina el asistente.
  3. 3Descarga Postventa para Windows, ábrelo y pulsa «Instalar». Las siguientes versiones se instalan encima, sin repetir el certificado.

¿Por qué el certificado? Postventa para Windows está firmado con un certificado propio. Hasta que usemos uno comercial, Windows necesita que confíes en él una vez en cada equipo. Va en «Personas de confianza», no como entidad raíz: solo sirve para reconocer este programa.

Con PowerShell como administrador, desde la carpeta donde lo descargaste:

Import-Certificate -FilePath .\postventa.crt -CertStoreLocation Cert:\LocalMachine\TrustedPeople
